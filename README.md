# 🎮 MindPlayAI – AI-Powered Rock Paper Scissors

MindPlayAI is an interactive Rock Paper Scissors game that uses computer vision and hand gesture recognition to let users play against the computer using real-time hand movements.

Instead of clicking buttons, players can show their hand gestures through their webcam to make their moves.

## ✨ Features

- Real-time hand gesture recognition.
- Webcam-based interaction.
- AI-powered gesture detection.
- Interactive Rock Paper Scissors gameplay.
- Dynamic score tracking.
- Responsive and user-friendly interface.

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling and interface
- **JavaScript** – Game logic and interactions
- **MediaPipe** – Hand gesture recognition

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/khushi-btw/MindPlayAI.git
```

### 2. Navigate to the project directory

```bash
cd MindPlayAI
```

### 3. Run the project

Open `index.html` in your browser.

Allow webcam access when prompted to start playing.

## 🎯 How to Play

1. Open the application.
2. Allow camera permissions.
3. Show your hand gesture in front of the webcam.
4. The system recognizes your move.
5. Play against the computer and track your score!
